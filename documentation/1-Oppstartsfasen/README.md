# 1 — Oppstartsfasen

Formål: etablere prosjektets fundament før planlegging starter — hva skal vi bygge, hvorfor,
for hvem, og innenfor hvilke rammer.

## Innhold

- **`product-brief.md`** — Produktbrief for SnowFinder: problem, målgrupper, løsning (kart,
  stedssider, filter, snøvarsel, SnowScore-forklaring), scope for v1, datakilder, arkitektur,
  risiko og suksesskriterier. Generert med `bmad-product-brief`-ferdigheten.
- Gruppekontrakt / roller og ansvar (legges til)
- Prosjektmandat / avtale med emneansvarlig, ev. karaktersette kriterier (legges til)

## Neste steg

Når brief er godkjent av gruppen, går arbeidet videre til
[`2-Planleggingsfasen/`](../2-Planleggingsfasen/) for krav, arkitektur og sprint-plan
(`bmad-prd`, `bmad-architecture`, `bmad-create-epics-and-stories`).
