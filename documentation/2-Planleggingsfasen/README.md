# 2 — Planleggingsfasen

Formål: oversette produktbrief til konkrete krav, arkitektur og en gjennomførbar plan.

## Innhold (legges til etter hvert)

- **PRD** — produktkravdokument (`bmad-prd`)
- **Arkitektur** — tekniske valg for SnowFinder: React/TypeScript/Vite-frontend, Leaflet-kart,
  Supabase (Postgres + Edge Functions), datapipeline mot MET/NVE/Kartverket/OpenStreetMap,
  SnowScore-beregning, varselmotor (`bmad-architecture`)
- **UX/UI-spesifikasjon** — `DESIGN.md` og `EXPERIENCE.md` for Norgeskart, stedssider, filter,
  SnowScore-forklaringsside (`bmad-ux`)
- **Epics og stories** — nedbrutte leveranser: stedskatalog og pipeline, SnowScore, kart og
  stedssider, filter, «bør ha»-funksjoner (`bmad-create-epics-and-stories`)
- **Sprint-plan / fremdriftsplan** (`bmad-sprint-planning`)
- **Testplan** — enhets-, egenskaps-, kontrakts-, sikkerhets- og E2E-tester
  (`bmad-testarch-test-design`)

## Forrige / neste steg

Bygger videre på [`1-Oppstartsfasen/`](../1-Oppstartsfasen/). Når planen er klar, styres
utviklingen i [`3-Gjennomføringsfasen/`](../3-Gjennomføringsfasen/).
