# Dokumentasjon — G18 SnowFinder (IBE160)

Denne mappen inneholder gruppens prosjektdokumentasjon for **SnowFinder**, organisert etter de
fire fasene i prosjektmodellen brukt i IBE160: oppstart, planlegging, gjennomføring og
avslutning.

| Mappe | Fase | Innhold |
|---|---|---|
| [`1-Oppstartsfasen/`](1-Oppstartsfasen/) | Oppstart | Produktbrief, mandat, roller, tidlige risikoer |
| [`2-Planleggingsfasen/`](2-Planleggingsfasen/) | Planlegging | Krav (PRD), arkitektur, epics/stories, sprint-plan, testplan |
| [`3-Gjennomføringsfasen/`](3-Gjennomføringsfasen/) | Gjennomføring | Sprint-status, statusrapporter, kodegjennomganger, endringer |
| [`4-Avslutningsfasen/`](4-Avslutningsfasen/) | Avslutning | Sluttrapport, retrospektiv, leveranse og presentasjon |
| [`assets/`](assets/) | — | Diagrammer, skjermbilder og bilder brukt i dokumentasjonen |

Dokumentene produseres i stor grad med BMAD-agentene og -ferdighetene installert i
`.agents/skills/` og `.claude/skills/` (f.eks. `bmad-product-brief`, `bmad-prd`,
`bmad-architecture`, `bmad-create-epics-and-stories`, `bmad-sprint-planning`,
`bmad-retrospective`). Rå arbeidsartefakter fra disse verktøyene lagres i `_bmad-output/`; de
versjonene som gjelder som gruppens offisielle leveranse, samles her i `documentation/`.

Produktet heter **SnowFinder** — en webapp som finner steder og tidspunkt med best
prognostiserte snøforhold, med **SnowScore** (0–100) som kjernemetrikk. Se
[`1-Oppstartsfasen/product-brief.md`](1-Oppstartsfasen/product-brief.md) for full
produktbrief.
