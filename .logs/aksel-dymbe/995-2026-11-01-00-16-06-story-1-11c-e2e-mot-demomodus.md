# Story 1.11c: E2E, CI og pre-push mot demomodus

## 2026-11-01 kl. 00:16 — Aksel Dymbe

### Oppgave
Implementere `spec-1-11c-e2e-mot-demomodus.md`: Playwright, CI og pre-push skal bruke `build:demo`, så de ikke avhenger av nett, og nye tester skal vise i nettleseren at hver modus bare leser sin egen datafil.

### Plan
- Spec: [`spec-1-11c-e2e-mot-demomodus.md`](../../project-workspace/implementation-artifacts/spec-1-11c-e2e-mot-demomodus.md)
- To Playwright-prosjekter med hvert sitt bygg og port, to nye spec-filer, fjerne rutene for `latest.json`, deretter kjøre E2E med og uten lokal fil og mutere `dataKilde` begge veier.

### Resultat
- `playwright.config.ts`: prosjektene `chromium` (port 4173, `build:demo`) og `normalmodus` (port 4174, `npm run build --ignore-scripts` til `node_modules/.cache/e2e-normal`, etter funn i gjennomgangen).
- Nye `tests/e2e/normalmodus.spec.ts` og `tests/e2e/demomodus.spec.ts`. `datagren.spec.ts` er slettet.
- Rutene og kommentarene for `latest.json` er fjernet fra `kart`, `filter`, `forklaring`, `gamle-data`, `sted` og `liste`. `tom.spec.ts` serverer live-data som `demo.json`.
- `ci.yml`, `.githooks/pre-push` og `README.md` bruker `build:demo`.
- Verifisert lokalt på Windows: lint, typecheck, `npm test` og `build:demo` er grønne. E2E ga 127 av 127 grønne både uten og med lokal `public/data/latest.json`.
- Mutasjon av `dataKilde`: alltid `demo` ga 2 røde i `normalmodus.spec.ts`, alltid `latest` ga 1 rød i `demomodus.spec.ts`. Første forsøk (`return 'demo'`) stoppet på `tsc -b` før testene startet og beviste ingenting, så det ble kjørt på nytt med mutasjoner som typesjekker. Kilden er tilbakestilt.
- Gjennomgang i tre lag: 4 funn rettet, 1 utsatt, og resten avvist (se spec-ens vurderingslogg). Viktigst: ingen sjekk kjørte selve `npm run build`. Nå gir `build` med `--mode demo` rødt i `normalmodus.spec.ts` (2 av 2).
- `reuseExistingServer` er `false`, så port 4173 og 4174 må være ledige. README og arkitekturen (begge kopier) beskriver de to byggene.
- Etter rettingene: lint, typecheck, 657 enhetstester, `build:demo` og 127 E2E-tester grønne lokalt.
- Commit `9a3f9be` og `bd63a21`, pushet til PR #78, som fortsatt er utkast. CI, E2E og `data` er grønne på Ubuntu.
